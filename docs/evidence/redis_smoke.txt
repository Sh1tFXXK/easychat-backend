## 四、结论

| 能力 | 证据 |
|---|---|
| 登录态存 Redis、登出立即失效 | `token revoked = 401` |
| 验证码 60s 冷却 + 一次性 | `cooldown = 429`、`replay = 400` |
| 未读点数：发送者不加、对方 +1 | `bob unread total = 1`、`alice unread total = 0` |
| 已读清零 | `bob unread after read = 0` |
| 未读叠加进会话列表 | `bob chats unread = 1` |
| 发消息失效列表缓存 | 最后一条消息从 `hello redis` 变成 `second message` |
| 在线状态心跳/TTL 过期 | `heartbeat = true`、`offline = false`、key TTL=90 |
| 批量在线状态 | `batch online count = 1` |
